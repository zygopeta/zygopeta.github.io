卡在一道 C 语言题上？先别急着看答案

这是给自己刷题做的一个小工具。把题干、输入输出格式、样例粘进去，选一个模式，AI 会按大一初学者的程度讲 —— 术语先用大白话解释，代码保证能直接 gcc 编译，还会顺手点出数组越界、scanf 忘写 &、= 和 == 这些老坑。

和直接问 AI 不一样的地方：题目、你自己写的代码、每一次讲题记录都会按题归档存下来，可以标「待攻克 / 需复习 / 已掌握」，换台电脑登录还能接着看。复习周翻一遍「需复习」比重新搜题省事得多。

五种讲题模式

选模式就提问，也可以在下面继续追问，AI 记得这道题前面聊了什么。

💡 思路提示
不直接给完整代码，分 3~5 步引导思考，点出关键知识点和易错处。适合自己先想。
📝 完整题解
题意拆解 → 算法思路 → 可编译的 C 代码 → 复杂度 → 测试用例（含边界）。
🔍 逐行讲解
针对你写的代码逐行解释，说明变量在循环里怎么变、每句在干什么。
🐛 帮我 Debug
把报错信息或错误现象一起贴进来，定位原因、给出改好的完整代码和验证方法。

另外还有自由追问：对任何一步没听懂，直接接着问，比如「为什么这里要用 & 取地址」。

怎么开始

  1. 点下面的按钮，在新标签页打开工具（会跳到工具自己的网址）。
  2. 用邮箱验证码登录：填邮箱 → 获取验证码 → 登录，新邮箱会自动注册，不用记密码。
  3. 新建题目：填标题和题干，可顺手贴上自己写的代码；点「保存题目」存到云端。
  4. 选一个模式，AI 会流式输出讲解；代码块可一键复制，生成中随时能停。
